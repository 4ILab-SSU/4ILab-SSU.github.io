# 코드 점검 — 2026-09-25

## 수정 사항

- 캐시: CSS 최적화가 끝난 뒤 실제 배포 파일의 내용으로 로컬 CSS·JS 버전을 지정합니다. 스타일이나 스크립트가 바뀌면 브라우저가 새 파일을 요청합니다.
- 구성원: 작은 화면에서 긴 이름·연구 분야·링크가 카드를 넘치지 않도록 하고, 졸업생 표에는 가로 스크롤을 제공합니다.
- 달력: 다크 모드에서 요일 글자의 색상과 배경을 명시했습니다.
- 사진: 사진이 없는 앨범과 장소는 공개 목록에서 제외합니다. 지도 데이터가 비어 있어도 오류가 나지 않으며, 클러스터에 묶인 장소도 버튼으로 팝업을 열 수 있습니다.
- 검색: 한국어 검색의 메뉴 제목과 결과 이동 주소에 현재 언어를 적용했습니다.
- 데이터: 지도·달력 JSON에 HTML 태그가 들어 있어도 스크립트 영역이 끊기지 않도록 처리했습니다.
- 정리: 사용하지 않는 이전 홈 화면 스타일, 중복 로고 스타일과 불필요한 클릭 처리 코드를 제거했습니다. 논문 수 검사의 고정값을 현재 BibTeX 데이터에서 계산하도록 바꿨습니다.

## 검증

- 콘텐츠 검사: 경고 0건, Jekyll production 빌드 성공.
- 정적 검사: 언어별 페이지 66개, 전체 HTML 67개, 로컬 CSS·JS 참조 1,285개의 최종 버전 확인.
- 브라우저 검사: 주요 페이지 14종 × 언어 2종 × 화면 폭 4종(320/390/768/1440px) × 테마 2종 = 224개 조합에서 가로 넘침·JavaScript 실행 오류 없음.
- 기능 검사: 검색의 키보드 선택, 지도 장소 선택 및 초기화, 빈 지도 처리, 모바일 메뉴, 언어 변경 시 쿼리·앵커 유지, 브랜드 다운로드 링크 확인.
- 달력: 해외 시간대에서도 한국 날짜 표시, 오늘 버튼, 자정·월 변경 확인.
- 섹션 간격: 연구 성과·연구 과제 페이지의 구역 사이 여백을 양쪽 언어에서 확인.
